#+TITLE: Referência de keybindings do Neovim
#+SUBTITLE: Extraída de =~/.dotfiles/nvim=
#+OPTIONS: toc:2

Cross-editor comparison: [[file:../editor-keybindings-comparison.org][custom keybindings grouped by functionality]].

Multi-step operations are grouped under one Org heading, even when their
bindings use different prefixes or modes. Follow the steps in order;
alternatives and cleanup commands are identified separately.

* Convenções

- =SPC= é o leader e o local leader.
- Scope: mappings declared in this configuration. Native commands and
  unchanged plugin defaults are included only when needed to complete a
  documented workflow, and are identified as such.
- Uma linha indicada como “com LSP” só existe em buffers aos quais um servidor
  LSP está anexado. Bindings de seleção exigem uma seleção Visual.

* Multi-step workflows

** Multiple cursors: select targets, edit, and clean up

Choose one way to create cursors, edit with the active cursors, then remove
them. Search-based creation uses the active search pattern; =*= is a native
way to set it from the word under the cursor.

*** Create cursors

| Context                | Key                      | Command / effect                                                               |
|                        |                          |                                                                                |
| Normal                 | m *                      | Create cursors for every match of the word under the cursor.                   |
| Normal, after a search | m s                      | Create cursors for every match of the active search.                           |
| Visual Line            | m c                      | Create a cursor at the beginning of each selected line and return to Normal.   |
| Visual                 | m r                      | Prompt for a pattern and select each match inside the selection with a cursor. |
| Normal / Visual        | m n / m p                | Add a cursor at the next / previous match.                                     |
| Normal / Visual        | m N / m P                | Skip the next / previous match without adding a cursor.                        |
| Visual                 | m \vert{}                | Prompt for a regex separator and split the selection into cursors.             |
| Normal                 | g m followed by a motion | Create cursors for each line covered by the motion.                            |
| Visual                 | g m                      | Create cursors for each line covered by the selection.                         |
| Visual                 | I / A                    | Create cursors at the beginning / end of each selected line and enter Insert.  |
| Normal / Visual        | C-q                      | Toggle a manual cursor at the current position.                                |

*** Replace a pattern only inside the visual selection

Use =m r= to select matches inside the selected region, then change all
matches together. Unlike a plain =:'<,'>s/A/B/g= command, this workflow
respects the selected columns rather than operating on entire lines.

| Step | Mode | Key / input | Command / effect |
|------+------+-------------+------------------|
| Select the region | Normal | v / V / C-v, then select | Use native characterwise, linewise, or blockwise Visual mode. |
| Select matches | Visual | m r, type pattern A, then RET | Answer the =Match:= prompt; create a cursor selecting each match inside the region. |
| Replace matches | Visual, active cursors | c, then type replacement B | Change every selected match together (native change command). |
| Finish editing | Insert, active cursors | ESC | Return to Normal mode. |
| Clean up | Normal, enabled cursors | ESC | Clear the additional cursors. |

Example: select a region, press =m r=, enter =foo= and press =RET=, then
press =c=, type =bar=, and press =ESC= twice.

*** Navigate or remove active cursors

| Context | Key | Command / effect |
|---------+-----+------------------|
| Normal / Visual, active cursors | Left / Right | Select the previous / next cursor. |
| Normal / Visual, active cursors | SPC x | Remove the current cursor. |
| Normal, disabled cursors | ESC | Re-enable cursors; this first press does not clear them. |
| Normal, enabled cursors | ESC | Clear all additional cursors. |

** Record and replay a macro

Choose a register when starting the recording, perform the editing
operation, then stop and replay it. Use =Q= to stop: this configuration maps
Normal-mode =q= to quit without saving.

| Step | Mode | Key | Command / effect |
|------+------+-----+------------------|
| Start recording | Normal | Q followed by a register, e.g. Q a | Invoke native =q= to record into the chosen register. |
| Stop recording | Normal | Q | Invoke native =q= again to finish recording. |
| Replay | Normal | @ followed by the register, e.g. @ a | Replay the recorded macro (native command). |
| Repeat replay | Normal | @ @ | Replay the last executed macro again (native command). |

| Move horizontally | Normal | s h / s l | Focus the window on the left / right. |

** Browse and edit directories with Oil

Oil opens the current file's directory as an editable buffer. File operations
are staged by editing its entries and applied only after saving and confirming
the operation preview. Oil handles directory buffers by default.

| Step | Context | Key | Command / effect |
|------+---------+-----+------------------|
| Open directory | Normal, editing buffer | \ | Open the current file's directory in Oil. |
| Open entry | Oil buffer | RET | Open the file or enter the directory under the cursor. |
| Parent directory | Oil buffer, Normal | BS | Go up one directory; outside Oil, keep opening the project file picker. |
| Create | Oil buffer | o / O, then type a name | Stage a new file; use a trailing slash for a directory. |
| Rename | Oil buffer | Normal editing commands | Edit an entry's name to stage a rename. |
| Delete | Oil buffer, Normal | d d | Remove an entry's line to stage deletion. |
| Apply operations | Oil buffer | :w | Review and confirm the pending filesystem operations. |
| Close | Oil buffer, Normal | \ | Return to the editing buffer. |

** Browse the project tree with Snacks Explorer

Snacks Explorer is an optional sidebar for exploring the project tree. It
opens at the current buffer's Git root, falling back to the current working
directory, and follows the current file. Oil remains the default directory
explorer and keeps its =\= binding.

| Step | Context | Key | Command / effect |
|------+---------+-----+------------------|
| Open explorer | Normal, editing buffer | SPC s e | Open Snacks Explorer at the project root. |
| Open entry | Explorer list | RET / l | Open a file or toggle a directory (Snacks default). |
| Collapse directory | Explorer list | h | Close the directory (Snacks default). |
| Parent directory | Explorer list | BS | Go up one directory (Snacks default). |
| Search | Explorer list | / | Focus the search input (Snacks default). |
| Toggle hidden / ignored | Explorer list | H / I | Toggle hidden or Git-ignored entries (Snacks defaults). |
| Toggle preview | Explorer list | P | Toggle the file preview (Snacks default). |
| Close | Explorer list, Normal | q / ESC | Close the explorer (Snacks defaults). |

** Search and resume the last picker

Choose a search source, select a result, then resume the picker if needed.
The resume command reopens the last picker, not necessarily the last text
search.

| Step | Mode | Key | Command / effect |
|------+------+-----+------------------|
| Search project text | Normal | SPC s g / SPC s w | Search project text / the word under the cursor. |
| Search buffer text | Normal | =SPC /= or =SPC s /= | Search lines in the current buffer / text in open buffers. |
| Open a result | Picker | RET | Confirm the selected result (Snacks default). |
| Resume | Normal | SPC s r | Resume the last picker. |

** Inspect diagnostics and choose an action

Navigation, inspection, and actions belong to the same troubleshooting
workflow. Code actions require an attached LSP server and depend on what
that server offers at the cursor.

| Step | Mode | Key | Command / effect |
|------+------+-----+------------------|
| Locate | Normal | [ d / ] d | Go to the previous / next diagnostic. |
| Browse a list instead | Normal | SPC s d / SPC q | Browse diagnostics with Snacks / populate the location list. |
| Inspect | Normal | SPC e | Show diagnostics in a floating window. |
| Act | Normal, with LSP | SPC c a | Request code actions at the cursor. |

** Copy text and replace a target with the register

First yank the source, then move to the target and replace it. The
replacement mappings use the selected register; an explicit register
prefix such as ="a= can be used for both the yank and replacement.

| Step | Mode | Key | Command / effect |
|------+------+-----+------------------|
| Copy source | Normal | y followed by a motion or text object | Yank the source into a register (native command). |
| Replace target | Normal | g r followed by a motion | Replace the target with the register contents. |
| Replace a line instead | Normal | g r r | Replace the current line with the register contents. |
| Replace a selection instead | Visual | g r | Replace the selected text with the register contents. |

The old =gra=, =gri=, =grn=, =grt=, and =grx= mappings are removed to avoid
conflicts with register replacement.

** Exchange two pieces of text

Mark the first piece, move to the second, then repeat the exchange command
to swap them. Cancel is an alternative to selecting the second piece.

| Step | Mode | Key | Command / effect |
|------+------+-----+------------------|
| Mark first piece | Normal | c x followed by a motion / c x x | Mark the motion's range / the current line for exchange. |
| Mark second piece and exchange | Normal | c x followed by a motion / c x x | Select the second range / line and exchange it with the first. |
| Use selections instead | Visual | X, then X on another selection | Mark the first selection, then exchange it with the second. |
| Cancel | Normal | c x c | Cancel the pending exchange. |

** Align text and accept or cancel the preview

| Step | Mode | Key | Command / effect |
|------+------+-----+------------------|
| Start with preview | Normal | g A followed by a motion or text object | Select the range and open Mini.align's preview. |
| Configure alignment | Mini.align session | Interactive prompts | Choose the alignment rules and inspect the preview. |
| Accept | Mini.align session | RET | Accept the previewed alignment. |
| Cancel instead | Mini.align session | ESC | Cancel the previewed alignment. |
| Alternative without preview | Normal | g a followed by a motion or text object | Align the selected range without preview. |

** Open a terminal and return to editing

| Step | Context | Key / command | Command / effect |
|------+---------+---------------+------------------|
| Open | Normal | t t | Run :terminal to open the integrated terminal. |
| Enter terminal input | Terminal buffer, Normal | i | Enter Terminal mode to send input to the terminal (native command). |
| Return to Normal | Terminal mode | ESC ESC | Leave terminal input mode. |
| Move to an editing window | Terminal buffer, Normal | s h / s j / s k / s l | Focus an existing editing window. |
| Resume terminal input | Terminal buffer, Normal | i | Re-enter Terminal mode (native command). |

** Completagem e snippets

| Tecla | Comando / efeito |
|-------+------------------|
| C-n / C-p | Seleciona o candidato seguinte / anterior. |

is unchanged.

* Objetos de texto

** Mini.ai

=mini.ai= substitui a resolução de objetos de texto por uma versão que procura
até 500 linhas e escolhe o objeto que cobre ou está mais próximo do cursor.
Use os identificadores abaixo depois de =a= ou =i=, com qualquer operador ou
em Visual.

| Tecla | Objeto de texto |
|-------+-----------------|
| a e / i e | Buffer inteiro. |
| a f / i f | Chamada de função, incluindo / excluindo os delimitadores. |
| a a / i a | Argumento de função, incluindo / excluindo a vírgula separadora. |
| a t / i t | Tag HTML/XML, incluindo / excluindo as tags. |
| a ? / i ? | Objeto definido interativamente por um padrão. |
| a ( / a [ / a { / a < e variantes =i= | Delimitadores balanceados. |
| a " / a ' / a ` e variantes =i= | Texto entre aspas. |
| a b / i b | Alias para delimitadores =()=, =[]= ou ={}=. |
| a q / i q | Alias para aspas =", ', `=. |
| a n / i n | Próxima ocorrência do objeto de texto. |
| a l / i l | Ocorrência anterior do objeto de texto. |

** Subpalavras Unicode

| Tecla | Comando / efeito |

| w / e / b / g e | Move por subpalavras para frente / fim / trás / fim anterior, com a mesma segmentação Unicode. |
