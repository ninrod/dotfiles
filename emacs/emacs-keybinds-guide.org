#+TITLE: Referência de keybindings do Emacs
#+SUBTITLE: Extraída de =~/.emacs.d/boot.org=
#+OPTIONS: toc:2

Cross-editor comparison: [[file:../editor-keybindings-comparison.org][custom keybindings grouped by functionality]].

Multi-step operations are grouped under one Org heading, even when their
bindings use different prefixes or modes. Follow the steps in order; rows
labelled as alternatives or cleanup are optional.

* Convenções

- Escopo: a maior parte deste documento cobre o nó =~* keybinds= de
  =boot.org=. A seção "Bindings declarados fora de *keybinds*" complementa
  os atalhos ativos declarados em outras partes do arquivo.
- Estados Evil: =N= (normal), =V= (visual) e =M= (motion).
- Sequências como =SPC d f= indicam teclas sucessivas, não teclas
  pressionadas simultaneamente.
- Os mapas específicos de modo podem sobrepor um atalho geral quando aquele
  modo ou buffer está ativo.

* Multi-step workflows

** Save a position and return to it

The Evil marker =z= stores one position; setting it again replaces the
previous position. This is separate from Emacs's mark ring (=g TAB=).

| Step | State | Key | Command / effect |
|------+-------+-----+------------------|
| Save | N, V, M | s m | Save the current position in marker =z= (=ninrod/evil-set-marker-z=). |
| Return | M | g m | Jump to marker =z= and center the destination line (=ninrod/evil-goto-marker-z=). |

** Record a macro and apply it to selected lines

Record the editing operation once, then select the target lines. The
custom replay command uses the last Visual selection's range, not just the
current cursor position.

| Step | State | Key | Command / effect |
|------+-------+-----+------------------|
| Start recording | N, V, M | m m | Record a macro in register =z= (=ninrod/evil-record-macro-z=). |
| Finish recording | N, V, M | m m | Invoke the recording command again to stop recording. |
| Select targets | N | V, then motions | Select the lines on which to replay the macro. |
| Apply | N, V, M | m a | Run ='<,'>norm @z= over the selected line range (=ninrod/apply-z-macro=). |
| Alternative recording | N | Q | Invoke =evil-record-macro= with an explicitly chosen register; =m a= still replays register =z=. |

** Create, visit, and remove a bookmark

| Step | State | Key | Command / effect |
|------+-------+-----+------------------|
| Create | N, V, M | s b | Save a named bookmark (=bookmark-set=). |
| Visit | N, V, M | s SPC | Choose a bookmark and jump to it (=bookmark-jump=). |
| Cleanup | N, V, M | s - | Delete a bookmark (=bookmark-delete=). |

** Narrow the editing scope and restore it

Choose the narrowing operation appropriate to the buffer. Rectangular
narrowing has its own matching restore command.

| Step | Context / state | Key | Command / effect |
|------+-----------------+-----+------------------|
| Narrow a rectangle | N, V, M | s n | Narrow a rectangular region (=rect-ext-narrow=). |
| Restore the rectangle | N, V, M | s w | Undo rectangular narrowing (=rect-ext-widen=). |
| Narrow an Org subtree | Org, N, V | , n | Restrict the buffer to the current subtree (=org-narrow-to-subtree=). |
| Restore the buffer | N, V, M | m w | Remove buffer narrowing (=widen=). |

** Split a window and move between windows

| Step | State | Key | Command / effect |
|------+-------+-----+------------------|
| Split | N, V, M | s y / s x | Split right / below and focus the new window. |
| Move horizontally | N, V, M | s h / s l | Focus the window to the left / right. |
| Move vertically | N, V, M | s j / s k | Focus the window below / above. |

** Edit an Org source block and return

| Step | Context / state | Key | Command / effect |
|------+-----------------+-----+------------------|
| Open | Org, N, V | , e | Edit the source block at point in its dedicated buffer (=org-edit-special=). |
| Commit and return | Org source / Emacs Lisp edit buffer, N | S | Write the edits back to the Org block and exit (=org-edit-src-exit=). |
| Abort and return | Org source / Emacs Lisp edit buffer, N | T | Discard the edit-buffer changes and exit (=org-edit-src-abort=). |

=S= and =T= are alternatives for finishing the same operation, not
successive steps. Their Org editing commands require an active source
editing session, even though the bindings also exist in Emacs Lisp mode.

** Inspect, edit, and recalculate Org table formulas

| Step | Context / state | Key | Command / effect |
|------+-----------------+-----+------------------|
| Inspect coordinates | Org, N | T @ | Toggle table coordinate overlays. |
| Inspect a field | Org, N | T ? | Show information about the current field. |
| Edit | Org, N | T f | Open the table formula editor (=org-table-edit-formulas=). |
| Apply and return | Formula editor | C-c C-c | Install the edited formulas and return to the table. |
| Recalculate | Org, N | T e | Recalculate the table with prefix argument =4=. |

** Copy or move an Org subtree

Copy or cut the subtree, move to the destination heading, then paste.
Cloning is an alternative that creates a copy without a separate paste step.

| Step | Context / state | Key | Command / effect |
|------+-----------------+-----+------------------|
| Copy | Org, N | S y | Copy the subtree (=org-copy-subtree=). |
| Cut instead | Org, N | S d | Cut the subtree (=org-cut-subtree=). |
| Paste at destination | Org, N | S p | Paste the copied or cut subtree (=org-paste-subtree=). |
| Clone instead | Org, N | S c | Clone the subtree with a time shift (=org-clone-subtree-with-time-shift=). |

** Code folding

Origami is enabled in programming modes and =vimrc-mode=, using ={{{= / =}}}=
markers with nested regions. Marker folds start closed when a buffer is opened.
Ordinary comments and unmarked code are not folded.
Org keeps its existing outline-based folding.

| Evil state | Key | Command / effect |
|------------+-----+------------------|
| Normal | TAB / za | Toggle the code fold at point. |
| Normal | zc / zo | Close / open the code fold at point. |
| Normal | zM / zR | Close / open all code folds. |

** Snippets

YASnippet is enabled in programming, text, Org, and configuration buffers.
Personal snippets live in =emacs/snippets/= (=~/.emacs.d/snippets/=).

| Evil state | Key | Command / effect |
|------------+-----+------------------|
| Normal | SPC i e | Expand the snippet key at the cursor and enter Insert state. |
| Normal | SPC i i | Select and insert a snippet, then enter Insert state. |
| Normal | SPC i n | Create a snippet (=yas-new-snippet=). |
| Normal | SPC i v | Visit a snippet's source (=yas-visit-snippet-file=). |
| Normal | SPC i d | Open the personal snippets directory in Dired. |
| Insert | TAB | Expand a snippet, or run the existing TAB command if no key matches. |
| Insert, active snippet | TAB / S-TAB | Move to the next / previous field. |

Normal-state TAB bindings remain unchanged. No additional plugin is needed.

* Bindings declarados fora de =* keybinds=

Os bindings desta seção são definidos em outros nós de =boot.org= e ficam
ativos após o carregamento dos respectivos pacotes ou modos. Blocos marcados
como =#+BEGIN_SRC text= foram deliberadamente excluídos: não são código
Emacs Lisp executado pelo tangling.
