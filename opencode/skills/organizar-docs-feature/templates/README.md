# {{TITULO}} — como retomar

Quando o usuário pedir para retomar esta feature, comece pelo [status](status.md). Ele indica onde paramos, o próximo passo e o que ainda o bloqueia. Siga os links necessários à tarefa, sem reler toda a investigação.

- [feature.md](feature.md): objetivo, requisitos e limites.
- [plan.md](plan.md): como implementar e verificar cada fatia.
- [problems.md](problems.md): questões abertas ou resolvidas e links para os `qN.md` com a discussão.
- [research/](research/): investigações e referências.
- [bugs/](bugs/): defeitos e evidências; a presença aqui não os inclui automaticamente no escopo.
